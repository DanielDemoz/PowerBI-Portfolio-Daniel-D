# Machine Tooling — Rod Variance Analysis

> **Category:** 🏭 Manufacturing & Quality Control

## Overview

Manufacturing quality dashboard analyzing dimensional variance in machined rods against specification tolerances.

## Business Questions

- Which machines or shifts produce the highest defect rates?
- Is variance trending within control limits?
- What is the cost impact of out-of-spec production?

## Key Metrics

- Mean & standard deviation by batch
- % within tolerance
- Cp / Cpk (process capability) — if modeled
- Scrap & rework cost

## Data Sources

- QC measurement logs
- Machine & operator master
- Production order data

## Report File

Open **`Machine_Rod_Variance.pbix`** in Power BI Desktop.

## Features

- Control charts by dimension
- Histogram / distribution views
- Filter by machine, product line, date
- Out-of-spec alert highlighting
