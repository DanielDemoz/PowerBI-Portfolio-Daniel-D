# Transit Forecast — Ridership Forecasting

> **Category:** 🚌 Transportation & Public Services

## Overview

Public transit analytics report combining historical ridership with forecast models to support capacity and service planning.

## Business Questions

- How is ridership trending by line and time of day?
- What does the forecast imply for peak capacity?
- Which routes show the strongest growth or decline?

## Key Metrics

- Daily / monthly boardings
- Forecast vs. actual variance
- Peak vs. off-peak split
- Year-over-year growth %

## Data Sources

- AFC / tap-in transaction data
- Schedule & route geometry
- External factors (events, weather) — optional

## Report File

Open **`Transit_Ridership_Forecast.pbix`** in Power BI Desktop.

## Features

- Historical trend with forecast band
- Route and station slicers
- Seasonality decomposition view
- What-if parameters for service changes
