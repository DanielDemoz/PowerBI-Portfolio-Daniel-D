## How to Use

1. Clone or download this repository.
2. Open any `.pbix` file in **Power BI Desktop** (requires a compatible version).
3. Read each project's `README.md` for context, data sources, and key metrics.

## Skills Demonstrated

- **Data modeling** — star schema design, relationships, calculated columns
- **DAX** — measures, time intelligence, KPI calculations
- **Visualization** — interactive dashboards, drill-through, bookmarks
- **Storytelling** — executive summaries and operational detail views

## Tools

- Microsoft Power BI Desktop
- Power Query (M)
- DAX
- Excel / CSV data sources
