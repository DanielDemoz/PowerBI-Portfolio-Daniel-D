## How to Use These Files

1. **Download Power BI Desktop** (free at powerbi.microsoft.com)
2. **Open any .pbix file** in Power BI Desktop
3. **Explore interactive dashboards** with filters and drill-down capabilities
4. **Review data model** relationships and DAX formulas
5. **See documentation** in each project's README.md file

Each folder includes:
- Interactive Power BI file (.pbix)
- Source data files (.csv)
- Static PDF snapshot (for quick preview without software)
- Detailed README.md (how to use, business context, technical details)
