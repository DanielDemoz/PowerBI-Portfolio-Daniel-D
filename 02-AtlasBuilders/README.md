# Atlas Builders — Construction Dashboard

> **Category:** 🏗️ Construction & Project Management

## Overview

Project portfolio dashboard for Atlas Builders tracking budgets, timelines, and resource utilization across active construction sites.

## Business Questions

- Are projects on budget and on schedule?
- Which trades or phases drive cost overruns?
- How is labor allocated across sites?

## Key Metrics

- Budget vs. actual spend
- Schedule variance (days)
- % complete by project
- Cost per square foot

## Data Sources

- Project master & WBS
- Cost transactions
- Timesheets / labor hours

## Report File

Open **`Atlas_Construction_Dashboard.pbix`** in Power BI Desktop.

## Features

- Project-level KPI cards
- Gantt-style timeline or phase breakdown
- Cost variance waterfall
- Filter by region, project manager, or status
