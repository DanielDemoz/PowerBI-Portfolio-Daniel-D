# Dominion Airlines — Traffic Dashboard

> **Category:** 📊 Transportation & Aviation

## Overview

Interactive dashboard analyzing airline traffic patterns, route performance, and passenger volume for Dominion Airlines.

## Business Questions

- Which routes carry the highest passenger volume?
- How does load factor vary by route and season?
- Where are delays or cancellations concentrated?

## Key Metrics

- Total passengers & flights
- Load factor (%)
- On-time performance
- Revenue per available seat mile (RASM) — if modeled

## Data Sources

- Flight operations (CSV/Excel)
- Route master
- Schedule & delay logs

## Report File

Open **`Dominion_Airlines_Traffic.pbix`** in Power BI Desktop.

## Features

- Route and hub slicers
- Month-over-month traffic trends
- Top/bottom route rankings
- Geographic map of route network (if geocoded)
