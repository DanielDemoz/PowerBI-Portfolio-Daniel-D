# ProFit Gym — Member Engagement

> **Category:** 💪 Wellness & Fitness

## Overview

Fitness industry dashboard measuring member engagement, retention, class attendance, and membership lifecycle for ProFit Gym locations.

## Business Questions

- Which members are at risk of churn?
- What classes and time slots drive the most engagement?
- How does retention vary by membership tier?

## Key Metrics

- Active members & new sign-ups
- Visit frequency & avg. visits per member
- Class attendance rate
- Monthly churn %

## Data Sources

- Membership CRM
- Check-in / access logs
- Class booking system

## Report File

Open **`ProFit_Gym_Engagement.pbix`** in Power BI Desktop.

## Features

- Cohort retention curves
- Engagement score by member segment
- Location and class popularity rankings
- Trend of at-risk members
