# Electrohub Sales — Sales Performance Report

> **Category:** 🛒 Retail & E-Commerce

## Overview

Retail and e-commerce sales dashboard for Electrohub covering revenue, product mix, channel performance, and regional trends.

## Business Questions

- Which categories and SKUs drive revenue?
- How do online vs. in-store channels compare?
- Where are we missing sales targets?

## Key Metrics

- Total revenue & units sold
- Average order value (AOV)
- Gross margin %
- Sales vs. target

## Data Sources

- POS / e-commerce orders
- Product catalog
- Store & region dimension

## Report File

Open **`Electrohub_Sales_Report.pbix`** in Power BI Desktop.

## Features

- Time intelligence (MTD, YTD, YoY)
- Product hierarchy drill-down
- Regional map or matrix
- Top N products & customers
