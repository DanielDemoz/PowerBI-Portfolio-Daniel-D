# Greenview Hospital — Admissions Analytics

> **Category:** 🏥 Healthcare & Patient Flow

## Overview

Healthcare operations dashboard tracking patient admissions, length of stay, bed utilization, and department-level volume for Greenview Hospital.

## Business Questions

- What are admission trends by department and payer?
- How does length of stay compare to benchmarks?
- Is bed capacity aligned with demand?

## Key Metrics

- Admissions & discharges
- Average length of stay (ALOS)
- Bed occupancy rate
- Readmission rate (if modeled)

## Data Sources

- ADT (admit/discharge/transfer) events
- Department & bed master
- Payer / diagnosis grouping — de-identified

## Report File

Open **`Greenview_Hospital_Admissions.pbix`** in Power BI Desktop.

## Features

- Daily census trend
- Department and unit breakdown
- Seasonal pattern analysis
- Capacity vs. demand view

*Note: Use synthetic or de-identified data only in portfolio samples.*
